HTML Basics

HTML is used to create and structure content on web pages.

HTML Tags

1. Unordered List Tag <ul>

The <ul> tag is used to create a list of items displayed with bullet points.

2. Image Tag <img>

The <img> tag is used to display an image on a webpage.

3. Link Tag <a>

The <a> tag is used to create a hyperlink to another webpage or website.

4. Line Break Tag <br>

The <br> tag is used to insert a line break and move text to the next line.
